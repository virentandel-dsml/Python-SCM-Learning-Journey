# Week 4 — Python for Supply Chain Analytics

## Overview

Week 4 focused on learning **Pandas** and using structured data analysis to solve practical Supply Chain Management scenarios, with a primary focus on **manufacturing operations**.

The goal was to move from NumPy-based array analysis toward working with business datasets using DataFrames, data filtering, aggregation, KPI calculations, and combining information from multiple datasets.

The exercises emphasized manufacturing areas such as **inventory, production performance, and machine utilization**.

## Week 4 Flagship Project

### Manufacturing Plant Performance Analysis

The flagship project focused on evaluating manufacturing plant performance by combining three key dimensions:

**Production Achievement → Machine Utilization → Inventory Position → Plant Performance Analysis**

### Analysis dimensions

- Production achievement against plan
- Production variance
- Machine utilization
- Inventory gap against safety stock
- Plant-level KPI aggregation
- Combining production and inventory datasets
- Consolidated plant performance view
- Identification of plants requiring attention

## Key Business Finding

The analysis created a consolidated plant-level view that brings together **production achievement, machine utilization, and inventory gap**.

This provides a structured basis for identifying manufacturing plants that require further operational investigation, rather than evaluating production, capacity, or inventory in isolation.

## Key Learning

The main progression in Week 4 was from basic DataFrame operations to applying **filtering, vectorized calculations, aggregation, `groupby()`, `concat()`, and `merge()`** to manufacturing SCM data.

The flagship project demonstrated how multiple operational datasets can be combined to create a **decision-oriented manufacturing performance view**.

This is another step toward using Python as a practical tool for **Supply Chain Analytics and manufacturing decision support**.
