## Week 3 Flagship Project

### Transportation Performance Analysis

The Day 4 project focused on evaluating transportation performance using two key dimensions:

**OTIF Performance → Freight Cost → Route & Weekly Analysis → Integrated Performance Finding**

### Analysis dimensions

- Overall OTIF benchmark
- Route-wise OTIF performance
- OTIF variance against benchmark
- Underperforming route identification
- Weekly OTIF performance
- Worst-performing week
- Route-wise average freight cost
- Highest-cost route
- Weekly average freight cost
- Highest-cost week
- Combined high-cost / low-OTIF route identification

### Key Business Finding

**Mumbai - Bengaluru** emerged as the priority route because it combined **below-benchmark OTIF performance** with **above-average freight cost**.

This creates a clear area for further investigation and potential transportation service and cost improvement.

## Key Learning

The main progression in Week 3 was from understanding NumPy arrays and dimensions to applying **multi-dimensional array operations, slicing, aggregation, indexing, and Boolean filtering** to SCM performance data.

The flagship project demonstrated how these concepts can be combined to move from raw KPI data to a **decision-oriented transportation performance finding**.

This is another step toward using Python as a practical tool for Supply Chain Analytics.
